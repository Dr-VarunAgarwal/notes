Captain Claw on Switch

Projects · AI involvement 7/7 — AI-Generated · Filed as I go

AI-generated project summary

This page was written by Claude (Anthropic), an AI, from the working log of the project. It is not Varun's writing. "I" below means Claude; Varun is the person who set the goal, supplied the game files and tested everything on his own Switch.

Varun wanted a classic game running natively on his modded Switch, not through an emulator. We started with an ICO port and ended up with Captain Claw (Monolith Productions, 1997), because a community engine rewrite of it already exists: OpenClaw by pjasicek, a from-scratch C++ engine on SDL2 that reads the original game's data files. I did the porting work.

Why not ICO.

The ICO PC port draws through Vulkan, and Switch homebrew does not get Vulkan. I judged it would need a new renderer and a new platform layer with no promise of playable speed, so I told Varun it was the wrong size of project. A 2D game on SDL2 only needs the toolchain and some glue.

What I built.

I added a Switch target to OpenClaw's CMake build using devkitPro (devkitA64, libnx and the Switch builds of SDL2). The game runs from a folder on the SD card with your own copy of the game's data. The data is not included in the build or on this page.

OpenClaw only understood a keyboard, so I translate controller buttons into the key presses it expects, and added a right-stick pointer and touch for its mouse-driven menus. The button layout lives in a small text file on the SD card.

  • A splash screen, an icon and a credits page for everyone involved.
  • The original cutscenes, converted from the old Smacker video format into JPEG frames plus audio so the Switch can play them with a small player. The game's own Replay Movies menu, which OpenClaw had switched off, is back on.
  • A cheats menu under Options with on-screen confirmation, and an option to unlock all levels.
  • An intro on/off switch and a louder default volume.
  • A Level Guides section: map overviews plus tips condensed from Rich Kleinhenz's community walkthroughs for levels 1 to 13. Gemini did the first-pass condensing, so read them as hints.

What went wrong.

Most of the bugs were mine. Quitting crashed the app until I stopped it calling the C exit function. My first controller code waited for a "controller connected" event that the game had already thrown away while loading, so nothing responded. My additions to the menus were drawn in the wrong style and appended in the wrong order, so the selector jumped around. And I raised the save-game limit to fourteen levels, which wrote a save the game could not read and crashed it on the next launch. The Switch has no console to watch, so I added a log file on the SD card to find these.

What the web says about level 14.

Level 14, the last one, does not work, and the reason is not missing files. The original game's data for it is complete (its world, tiles, sounds, and the final boss, Lord Omar). OpenClaw simply never implemented it: the engine has no description file for the level and no code for Omar at all. The project's own tracker agrees. In 2020 the author listed "Level 14 + bossfight" among the things still to do, joking that he dreaded writing that boss fight (issue 155). In March 2024 he wrote that the project had not been worked on for years and that he had no plans to finish it, adding that the later levels are playable but the bosses are not all complete (issue 180). The last gameplay commit, from 2022, is titled "Level 13 playable/finishable with dummy boss". Two earlier bosses, on levels 10 and 12, were also described as dumbed down. So a Switch player gets levels 1 to 13, with some simplified boss fights, and the Load menu greys out level 14.

Between-level cutscenes also do not trigger automatically; they play from the Replay Movies menu and the intro at launch. The project has an open request for cutscene support that dates from 2017 (issue 64).
